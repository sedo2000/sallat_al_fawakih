# # سلة الفاكهة 🍎

متجر توصيل حقيقي مبني بـ:
- Node.js + Express
- PostgreSQL
- JWT + HttpOnly Cookie
- bcrypt
- Multer لرفع الصور
- HTML/CSS/JavaScript بواجهة Mobile First

## التشغيل محلياً

1. ثبّت Node.js 20+ وDocker.
2. انسخ `.env.example` إلى `.env` وعدّل القيم.
3. شغّل قاعدة البيانات:

```bash
docker compose up -d
```

4. أنشئ الجداول:

```bash
psql "postgresql://postgres:postgres@localhost:5432/sallat_fawakih" -f schema.sql
```

5. ثبّت الحزم:

```bash
npm install
```

6. شغّل:

```bash
npm run dev
```

ثم افتح:
`http://localhost:3000`

## حساب الإدارة

يُنشأ تلقائياً عند تشغيل السيرفر إذا وضعت:
- `ADMIN_EMAIL`
- `ADMIN_PASSWORD`

في `.env`.

> غيّر كلمة مرور الإدارة وJWT_SECRET قبل النشر.

## ملاحظات النشر

للمتجر التجاري الفعلي:
- استخدم HTTPS.
- استخدم PostgreSQL مُداراً أو خدمة موثوقة.
- انقل الصور إلى Object Storage مثل S3-compatible storage بدلاً من مجلد uploads المحلي.
- ضع CORS على نطاق المتجر الحقيقي فقط.
- استخدم reverse proxy مثل Nginx/Cloudflare.
- أضف بوابة دفع محلية مناسبة قبل تفعيل الدفع الإلكتروني.
- أضف مزود خرائط/تحديد موقع إذا أردت اختيار الموقع من الخريطة.
- أضف إشعارات WhatsApp/Telegram/SMS للطلبات حسب الخدمة التي تختارها.
